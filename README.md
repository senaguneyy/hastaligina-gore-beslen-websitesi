 Hastalığına Göre Beslen Web Sitesi

** Proje Amacı
Bu web sitesi, kullanıcıların mevcut hastalıklarına göre tüketebilecekleri yiyecek ve içecekleri öğrenmelerini sağlar. Ayrıca önerilen besinlere ait sağlıklı tarifler sunar.

** Kullanılan Teknolojiler
- HTML
- CSS
- PHP
- MySQL
- XAMPP

** Özellikler
- Hastalığa göre yiyecek önerileri
- Hastalığa göre içecek önerileri
- Tarif önerileri
- Kullanıcı kayıt ve giriş sistemi

** Veritabanı
Projede MySQL veritabanı kullanılmıştır.
Veritabanı dosyası: giris_ekrani.sql

** Nasıl Çalıştırılır?
1. XAMPP kurulmalı
2. Apache ve MySQL başlatılmalı
3. giris_ekrani.sql dosyası phpMyAdmin üzerinden import edilmeli
4. Proje dosyaları htdocs klasörüne atılmalı
5. Tarayıcıdan http://localhost/proje/anasayfa.html ile çalıştırılmalı
